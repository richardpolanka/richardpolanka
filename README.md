## 🛠 Under the hood

`Next.js 16` `TypeScript` `Drizzle` `Neon Postgres` `Better Auth` `Tailwind` `Stripe` `Vercel`

~144k lines, built solo. The bits I'm proud of:

🧩 **Lessons are documents.** Calculators and simulators are nodes inside a TipTap editor, so new material gets written, not hard-coded.

⚔️ **Challenger.** Word of the day, leaderboards, and a map battle where students fight over regions of the country.

🏫 **Schools.** Their own courses, admins and billing, in the same database without leaking into the public side.
